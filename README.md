 Autonomous Multi-Agent IT Help Desk System 
Role: Lead Developer 
Tech Stack: AutoGen, LangGraph, OpenAI GPT-4, Streamlit, Kubernetes, Docker, Azure Cognitive Services 
I architected and developed a fully autonomous multi-agent IT help desk solution that automated over 60% of first-level support tickets 
across enterprise environments. Leveraging LangGraph-style agent workflows and human-in-the-loop reinforcement learning (RLHF), the 
system reduced ticket turnaround time by 50%, driving operational efficiency for IT departments. 
Designed for scalable cloud deployment on Azure Kubernetes Service (AKS), it supports dynamic load balancing and real-time 
conversational AI integration. The system incorporates advanced orchestration of autonomous AI agents using OpenAI APIs and Streamlit 
for user-friendly dashboards, laying a foundation for enterprise-grade autonomous AI deployments in IT service management.
